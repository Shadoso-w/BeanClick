## [0.1.0] - 待发布

### 新增

**M0 — 立项**

- 项目立项，开发手册 v0.2 定稿（第 17 节 8 项待确认全部关闭）

**M1 — 数据模型与应用外壳**

- 数据层：Drift schema v1，5 张表（`coffee_beans` / `grinders` / `brew_logs` / `recipes` / `app_settings`），
  外键 `ON DELETE SET NULL`，建库时种入 7 项默认设置
- 仓储层：豆库、磨豆机、冲煮记录、设置四个 Repository
  - 余量自动扣减规则落地（新建按粉量扣、编辑按差值补扣、删除不回补、下限 0）
  - 调磨对比查询（同豆同磨按刻度升序）、最近一杯（复制上次的数据来源）
- 领域层：5 个实体 + 4 个枚举，全部支持 JSON 往返（导出功能基础）
- 状态层：Riverpod providers（数据库、仓储、主题、列表、设置）
- UI：咖啡棕主题（浅色米白 / 深色深棕黑）、4 tab 外壳 + 中间 FAB、
  记录 / 豆库 / 统计 / 我的四页骨架与空状态
- 设置项真读写数据库：主题模式（浅色/深色/跟随系统）、冲煮后自动扣减余量

**M2 — P0 表单**

- **咖啡豆表单**：新增 / 编辑 / 删除；名称必填校验；产地、庄园、处理法、
  烘焙度、烘焙日期、风味标签、余量与购入总重（含消耗比例实时提示）、价格、备注
- **磨豆机表单**：新增 / 编辑 / 删除；品牌与型号必填；刀盘类型（含常用快捷项）、
  刻度单位、零点、每圈 click；底部实时预览 `C40 / 22 click / 零点 0` 展示格式
- **冲煮记录表单**：新增 / 编辑 / 删除
  - 方法选择（手冲 / 摩卡壶 + 可展开的更多方法）
  - 豆子与磨豆机下拉，可在表单内**就地新增**并自动选中
  - 研磨刻度与 click；粉量 / 水量填写后**自动算出粉水比**
  - 水温、总时间（实时显示 `m:ss`）、滤杯、冲煮时间可改
  - 评分（1–5 星，可点掉取消）、风味标签、备注、「标记为最佳参数」
- **复制上次**（手册 §8）：记录页 FAB 带着上次参数直接进表单；
  刻意**不继承评分、备注与最佳标记**，且不继承记录 id（生成新记录而非覆盖）
- **摩卡壶专属字段**：火力、出液量、上壶预热（选摩卡壶时才出现）
- **专业字段折叠**：TDS、萃取率、水质 ppm、环境温湿度、豆温、压力
- **余量联动提示**：保存时按设置自动扣减；余量不足则扣至 0 并弹出「余量不足」提示
- **删除一致性**：删除豆子 / 磨豆机后历史记录保留、外键置空；
  删除记录不回补余量（手册 §6.2）
- 表单字段加了稳定的 `Key`（如 `brew.dose`），便于测试与后续自动化

**M2.5 — P0 导出（收口）**

- **JSON 完整备份**：4 张表（咖啡豆 / 磨豆机 / 冲煮记录 / 配方）全字段导出，
  带 `schemaVersion`、`appVersion`、导出时间与各表计数；缩进 2 空格，人也能读
- **CSV 表格**：4 张表分段拼在同一文件，中文表头；**带 UTF-8 BOM**，
  Excel / WPS 打开中文不乱码
- **导出时二选一**（手册 §17 决策 8）：设置 → 导出数据 → 弹窗选择，
  **JSON 为默认**；选择会写入设置表，下次默认选中上次用过的格式
- **导出后分享**：文件写入应用文档目录（不是临时目录，取消分享后仍可找回），
  再唤起系统分享面板让用户保存或发送；分享失败不影响文件已写成功的事实
- **CSV 注入防护**：以 `= + - @` 开头的用户输入会加单引号前缀，
  避免表格软件把它当公式执行
- **备份可读回**：`decodeJson` 能把备份解析回实体，为下一步「导入」预留落点，
  并有往返一致性测试守住
- `ExportService` 抽出 `Exporter` 接口，UI 只依赖接口，便于测试注入
